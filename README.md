# BooksCollector Tests

Этот проект содержит тесты для класса `BooksCollector`.

## Описание тестов

Реализованные тесты охватывают следующую функциональность:

*   **Добавление новых книг:**
    *   Проверка успешного добавления уникальных книг.
    *   Проверка, что дубликаты не добавляются.
    *   Проверка, что книги с некорректным названием (длиннее 40 символов или пустые) не добавляются.
*   **Установка и получение жанра:**
    *   Проверка успешной установки жанра для существующей книги.
    *   Проверка, что некорректный жанр не устанавливается.
*   **Работа с избранным:**
    *   Проверка добавления книги в избранное.
    *   Проверка, что в избранное нельзя добавить несуществующую книгу.
    *   Проверка получения списка избранных книг.

## Запуск тестов

Для запуска тестов необходимо установить `pytest`. Затем выполните команду `pytest` в директории с файлом `tests.py`.
